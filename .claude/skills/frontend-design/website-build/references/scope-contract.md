# Website Build Skill Boundary Contract

This skill consumes frontend design decisions and turns them into implementation-ready structure and gates.

## Required Upstream Input
- If available, use `frontend-design` output as source of truth for tokens, states, and responsive behavior.
- If not available, request or infer a minimal temporary design contract and mark it as provisional.

## In/Out Rules

### Inputs
- design contract (preferred)
- required pages/flows and content
- stack/runtime constraints

### Outputs
- IA and page-level decomposition
- section/component contracts
- accessibility/performance/SEO gates
- implementation handoff checklist

### Non-goals
- redesigning visual language
- broad brand strategy work
- backend architecture design
