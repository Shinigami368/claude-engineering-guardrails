# investor-outreach

Investors skim. Write like it.

## Activation signals

- "Draft a cold email to [fund]"
- "Write a forwardable intro blurb"
- "Follow-up after the partner meeting"
- "Monthly investor update"
- Any ask that names a specific fund, partner, or thesis.

## Non-negotiables

| Rule | Why |
|---|---|
| One investor, one message | Template-smell kills replies. |
| Lead with a concrete number or fact | Adjectives don't prove traction. |
| Ask is exactly one next step | Ambiguity is the default no. |
| Target word count: 80–130 | Anything longer gets archived. |
| No claim without evidence behind it | Investors will check. |

If the user hasn't provided a personalization hook (portfolio fit, a specific post, a warm connection, a thesis match), **ask for one** before drafting. Otherwise label the output as "template — needs personalization" so the user doesn't send it raw.

## Cold email anatomy

```
Subject:      specific claim or number, ≤ 60 chars
Opener:       why THIS investor (one sentence)
Body:         what you do + why now + the proof (2–4 sentences)
Ask:          a single, low-friction next step
Sign-off:     name, role, one credibility anchor
```

Skip the opener if a mutual intro already exists — jump straight to the body.

## Follow-up cadence

| Day | Message |
|---|---|
| 0 | Initial send |
| +4 to +5 | Short bump with one new data point (not just "checking in") |
| +10 to +12 | Clean close — "happy to revisit when X lands" |

Stop after three touches unless the user explicitly wants a longer sequence. Don't confuse persistence with annoyance.

## Warm-intro requests

The connector should be able to forward your message in under 10 seconds. Provide:

- One-sentence framing of the fit ("B is building X; I thought of you because…").
- A forwardable blurb, ≤ 100 words, self-contained (assume the investor won't read the wrapper).
- An explicit "only if it's easy for you" opt-out.

## Post-meeting follow-up

Structure: what was discussed → what you promised → one new proof point (if available) → the next step. If you promised a doc, attach it in this email, not a later one.

## Process-mode investor updates

Monthly or bi-weekly during an active raise:

- Headline metric with direction of travel.
- One win, one challenge, one ask.
- Keep it under 200 words. Investors talk to each other — consistency across updates matters.

## Before sending — fast checklist

- [ ] Personalization line isn't interchangeable with another fund.
- [ ] The ask is a single, binary next step.
- [ ] No hype adjectives ("revolutionary", "disruptive", "game-changing").
- [ ] Every number has a source the user can defend.
- [ ] Word count is tight.
