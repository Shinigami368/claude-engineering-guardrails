# Social Content Post Templates

## Thread Templates

### Educational Thread Structure

```
HOOK (Tweet 1)
┌─────────────────────────────────────────┐
│ [Provocative statement or stat]         │
│                                         │
│ Here's why... [Thread]                  │
└─────────────────────────────────────────┘

CONTENT (Tweets 2-N)
┌─────────────────────────────────────────┐
│ 2. [First point with example]           │
│    - Sub-detail                         │
│    - Sub-detail                         │
├─────────────────────────────────────────┤
│ 3. [Second point with example]          │
│    - Sub-detail                         │
│    - Sub-detail                         │
├─────────────────────────────────────────┤
│ 4. [Third point]                       │
│    ...                                  │
├─────────────────────────────────────────┤
│ 5. [Key takeaway]                       │
└─────────────────────────────────────────┘

CLOSER (Final Tweet)
┌─────────────────────────────────────────┐
│ [Call to action + relevant hashtags]    │
│                                         │
│ 🔁 If this was useful, share            │
│ ❤️ Follow for more                      │
└─────────────────────────────────────────┘
```

### Behind-the-Scenes Thread

```
TWEET 1: HOOK
"Here's what really happened with [project/event]..."

TWEET 2: CONTEXT
"The brief was simple: [goal].
The deadline was [timeframe].
The budget was [amount]."

TWEET 3: CHALLENGE #1
"Problem #1: [description]
How we solved it: [approach]"

TWEET 4: CHALLENGE #2
"Problem #2: [description]
What we tried that failed: [attempt]
What actually worked: [solution]"

TWEET 5: RESULT
"Final result after [timeframe]:
📊 [Metric 1]: [change]
📊 [Metric 2]: [change]
📊 [Metric 3]: [change]"

TWEET 6: LESSON
"The biggest lesson: [insight]"

TWEET 7: CTA
"What should we try next? Reply 👇"
```

### Hot Take Thread

```
TWEET 1: THE TAKE
"Unpopular opinion:
[Strong opinion that will get attention]"

TWEET 2: EVIDENCE #1
"Here's why I believe this:
[Point 1 with evidence]"

TWEET 3: EVIDENCE #2
"[Example that supports the take]"

TWEET 4: EVIDENCE #3
"Data point: [stat or research]"

TWEET 5: COUNTERARGUMENT
"I know what you're thinking: [counter]
And here's why you're still wrong: [rebuttal]"

TWEET 6: CLARIFICATION
"[Nuance - things that are NOT included in the take]"

TWEET 7: ENGAGEMENT
"Agree or disagree? 👇"
```

## TikTok Script Templates

### Hook-Based Structure (60 seconds)

```
SECONDS 0-3: HOOK
"Stop doing [X] if you want [Y]"
OR
"Here's the [mistake] that [cost/consequence]"
OR
"The real reason you're [problem]..."

SECONDS 3-15: CREDIBILITY
"After [N] years of [experience]
working with [relevant context]..."

SECONDS 15-50: CONTENT DELIVERY
"[Main teaching points - fast paced]
Use text overlays for key points
Cut every 2-3 seconds"

SECONDS 50-55: VALUE ADD
"Bonus tip: [additional insight]"

SECONDS 55-60: CTA
"Follow for more
Like this if you learned something"

TEXT OVERLAYS THROUGHOUT
- Hook words on screen
- Key points in large text
- Timer/counter effects
```

### Storytelling Structure (60 seconds)

```
SECONDS 0-5: THE SITUATION
"[Setup - who, what, where]
I was [context] when [event]"

SECONDS 5-15: THE CHALLENGE
"Suddenly, [problem occurred]
Everyone was [reaction]"

SECONDS 15-35: THE JOURNEY
"We had to [approach]
Then [what happened next]
Which made us realize [insight]"

SECONDS 35-50: THE RESOLUTION
"In the end, [result]
And the biggest lesson was [takeaway]"

SECONDS 50-55: THE MORAL
"[One sentence moral]"
"You can apply this by [action]"

SECONDS 55-60: CTA
"Repost to someone who needs this"
```

## Thread Templates by Use Case

### Announcement Thread
```
1. [Teaser/Hook]
2. [What it is - brief]
3. [What it does - benefits]
4. [How it works - mechanics]
5. [Who it's for]
6. [Pricing/Availability]
7. [CTA - link in bio]
```

### Tool Recommendation Thread
```
1. [Hook - problem you solve]
2. [The tool + what it is]
3. [Why you chose it over alternatives]
4. [Key features - 3-5 bullets]
5. [Your results with it]
6. [Any downsides]
7. [CTA - your site/review]
```

### Case Study Thread
```
1. [Hook - result achieved]
2. [Client background]
3. [Problem/challenge]
4. [Approach/solution]
5. [Key steps taken]
6. [Results - specific numbers]
7. [Key learning/takeaway]
8. [CTA - offer to help]
```

## Engagement Templates

### Question Formats
```
"Reply with your [topic] and I'll [response format]"

"What's your take on [controversial topic]?"

"What's the one [advice] you wish you knew about [topic]?"

"Hot take: [opinion] | Agree or disagree?"

"Drop an emoji that describes your experience with [topic]"

"Quote tweet with your [topic] and I'll [action]"
```

### Fill-in-the-Blank Posts
```
"The best [topic] I've ever read is..."
"If I could only recommend one [product], it would be..."
"The most underrated [skill/tool] is..."
"One thing I wish I knew about [topic] is..."
"Stop [bad habit] and start [good habit] instead"
```

## Evergreen Content Templates

### Listicle (Top N Things)
```
"[Number] [adjective] [topic] that [outcome]"

For each item:
"#[Number] [Headline]
[Why it matters]
[Example or elaboration]"

"[Closing statement]
🔖 Save this"
```

### Myth-Busting Template
```
"Everyone says [common belief].
But here's what's actually true:"

"[Myth #1]: [explanation]
[Truth #1]: [reality]"

"[Myth #2]: [explanation]
[Truth #2]: [reality]"

"[Summary - what to do instead]
📌 Remember: [key takeaway]"
```

### Step-by-Step Process
```
"Here's exactly how to [achieve X]:"

"Step 1: [What to do]
→ Why it matters: [explanation]
→ Pro tip: [insider knowledge]"

[Repeat for each step]

"⚠️ Common mistakes to avoid:
• [Mistake 1]
• [Mistake 2]

Ready to get started? 👇"
```
