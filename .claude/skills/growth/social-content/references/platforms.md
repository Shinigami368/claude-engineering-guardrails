### Hashtag Strategy
- **Minimum**: 1-2 relevant hashtags
- **Maximum**: 3-5 hashtags (Engagement drops beyond)
- **Format**: Mix of broad (#business) + specific (#saas)
- **Placement**: End of post OR scattered naturally

## LinkedIn Specifics

### Algorithm Preferences
1. **Comments > Likes**: Reply to commenters increases reach
2. **Early engagement**: First hour matters most
3. **Connection weight**: Interactions from connections rank higher
4. **Industry relevance**: Topic consistency helps

### Optimal Posting Times
| Timezone | Best | Good | Avoid |
|----------|------|------|-------|
| EST | 7-8am, 12pm, 5-6pm | 8-9am, 1-2pm | 9pm+, 6am- |
| GMT | 7-8am, 12pm, 5-6pm | 8-9am, 1-2pm | 10pm+, 6am- |

### Document Carousel Specs
- **Slide count**: 5-10 slides optimal
- **Aspect ratio**: 4:5 or 1:1
- **File type**: PDF only
- **Max file size**: 100MB
- **First slide**: Title + Hook (most important)

## TikTok Specifics

### Algorithm Factors (in order of importance)
1. **Completion rate**: Watch time % is king
2. **Engagement**: Likes, comments, shares, saves
3. **Trending sounds**: Sound + trending audio
4. **Hashtags**: Discovery through tags
5. **Effects**: Using trending effects

### Optimal Posting Times
| Timezone | Best | Good |
|----------|------|------|
| EST | 7-9am, 12-3pm, 7-9pm | 10-11am, 4-6pm |
| PST | 7-9am, 12-3pm, 7-9pm | 10-11am, 4-6pm |

### Video Specs
| Spec | Value |
|------|-------|
| Duration | 15sec - 10min (new accounts: 60sec default) |
| Aspect ratio | 9:16 (full screen) or 1:1 |
| Resolution | 1080×1920 minimum |
| Frame rate | 24-60fps |
| File format | MP4 or MOV |
| Max file size | 287MB (up to 4GB with ads) |

### Caption Strategy
- **Hook first**: First 3 seconds hook viewers
- **Keywords**: Include searchable terms
- **Call to action**: "Follow for more" or question
- **Emoji**: Increases engagement 3-5%
- **Length**: 80-100 characters optimal

## YouTube Specifics

### Thumbnail Specs
| Spec | Value |
|------|-------|
| Resolution | 1280×720 (minimum 640×360) |
| Aspect ratio | 16:9 |
| File format | JPG, PNG |
| Max file size | 2MB |
| Text | 30% coverage max, large readable font |
| Face | Include face for 30% higher CTR |

### Title Best Practices
- **Length**: 50-60 characters (truncation avoided)
- **Format**: [Hook] + [Topic] + [Qualifier]
- **Numbers**: Odd numbers > even (3 tips vs 4 tips)
- **Keywords**: Put primary keyword first
- **Avoid**: ALL CAPS, clickbait (bad for retention)

### Description Template
```markdown
[Hook line - 1-2 sentences]

⏱️ TIMESTAMPS
00:00 - Intro
00:30 - Section 1
02:00 - Section 2
[etc]

📚 WHAT YOU'LL LEARN
- [Learning point 1]
- [Learning point 2]
- [Learning point 3]

🔗 LINKS
[Links mentioned in video]

#hashtag1 #hashtag2 #hashtag3
```

## Cross-Platform Considerations

### Content Adaptation Guide
| From → To | Adaption Notes |
|-----------|----------------|
| LinkedIn → Twitter | Condense, add hashtags |
| LinkedIn → Instagram | Visual-first, carousels work |
| YouTube → TikTok | Vertical cut, faster pace, captions essential |
| Blog → Twitter | One insight per tweet, thread format |
| Blog → LinkedIn | Expand with takeaways |

### Platform Voice Guide
| Platform | Voice |
|----------|-------|
| Twitter | Direct, punchy, professional but casual |
| LinkedIn | Professional, thought-provoking, expertise |
| Instagram | Visual storytelling, aspirational |
| TikTok | Authentic, entertaining, fast-paced |
| YouTube | Educational, thorough, authoritative |
| Facebook | Community-focused, conversational |
