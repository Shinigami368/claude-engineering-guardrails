# Skill: free-tool-strategy

## When To Activate

Use this skill when:
- the user wants to evaluate or plan an interactive free tool for acquisition
- the task is engineering-as-marketing strategy rather than a downloadable lead
  magnet
- the user needs to choose between calculators, generators, analyzers, or
  similar tool concepts
- the task is to assess whether a free tool is worth building and maintaining

Use `lead-magnets` for static or downloadable content offers rather than
interactive tools.

## Context Prerequisites

- Check `.claude/product-marketing-context.md` first if it exists.
- Clarify:
  - the core product and buyer
  - the marketing goal
  - technical build capacity
  - maintenance bandwidth
  - promotion budget
- Clarify whether the expected outcome is:
  - leads
  - SEO traffic
  - links
  - brand awareness
  - product education

Use the bundled tool-type reference for examples and format guidance.

## Discovery Questions

- What real problem could a free tool solve?
- How adjacent is that problem to the core product?
- What existing tools or workarounds does the audience use now?
- How unique would this tool be versus existing options?
- Can the team ship and maintain a credible MVP?
- What lead-capture model, if any, fits the tool?

## Decision Framework

- Solve a real problem that stands on its own.
- Keep the tool adjacent to the core product so the path to revenue is natural.
- Prefer a simple, focused MVP over a feature-rich tool with maintenance drag.
- Evaluate build cost against realistic lead or link value.
- Decide gating, SEO, and promotion strategy as part of the concept, not after
  launch.

## Output Structure

1. TOOL RECOMMENDATION

State the best-fit tool concept and the user problem it solves.

2. STRATEGIC FIT

State why the tool fits the product, audience, and acquisition goal.

3. MVP SCOPE

State the smallest credible version, what to include, and what to defer.

4. CAPTURE AND DISTRIBUTION PLAN

State the gating model, landing-page approach, SEO angle, and promotion plan.

5. GO OR NO-GO CHECK

State the main risks, maintenance burden, and whether the tool is worth
  pursuing now.

## Honesty And Non-Goals

- Do not recommend a free tool that has weak adjacency to the core product.
- Do not treat “interactive” as inherently better than a simpler lead magnet.
- Do not ignore maintenance cost after launch.
- Do not assume search demand or linkability without evidence.
- Do not use this skill as a substitute for detailed implementation planning of
  the tool itself.
