# content-engine

The failure mode this skill exists to prevent: writing one post and pasting it into five platforms. Each platform rewards a different shape. Respect that or get ignored.

## Activation signals

- "Write an X thread / LinkedIn post / TikTok script / YouTube hook."
- "Repurpose this [article / podcast / demo] across channels."
- Content calendar for a launch or milestone.
- Adapting a single anchor asset into multi-platform variants.

## Discovery — ask before drafting

Pin these four before writing anything:

| Input | What you need |
|---|---|
| Source asset | The anchor — article, video, memo, demo, launch doc |
| Audience | Builders, operators, customers, investors, recruits, general |
| Platform(s) | X, LinkedIn, TikTok, YouTube, newsletter, or some mix |
| Goal | Awareness, conversion, authority, hiring, launch amplification, engagement |

If any are missing and non-obvious from context, ask. Guessing the goal produces content that doesn't convert on anything.

## Non-negotiables

1. Platform-native shape. No cross-posted identical copy unless the user explicitly asks for it.
2. Hooks beat summaries. The first line earns the second.
3. One idea per post — bundling ideas halves the reach of each.
4. Specifics over slogans. "$18k MRR in 90 days" beats "strong early growth."
5. The ask is small and clear. Big CTAs at low trust get ignored.

## Platform playbook

### X
- Open fast. No "I've been thinking a lot about…" warmups.
- One idea per tweet in a thread; each tweet must earn the next click.
- Links belong at the end, not mid-thread, unless the link *is* the payoff.
- Hashtags: one or zero, never three.

### LinkedIn
- First line carries the whole post — assume the "…see more" truncation.
- Short paragraphs, whitespace-heavy.
- Explicit framing works here: "Three things I learned from X," "What nobody tells you about Y."
- LinkedIn tolerates earnestness. X punishes it. Don't swap the voices.

### TikTok / short video
- First 3 seconds must interrupt a scroll. Visual change, unexpected claim, or direct address.
- Script around what the viewer *sees*, not just what they hear.
- One demo, one claim, one CTA — cramming more than one kills completion rate.

### YouTube
- Show the payoff in the first 15 seconds.
- Chaptered structure; each chapter refreshes visuals ~every 20–30 seconds.
- Retention dies on static talking heads. Cut to the thing.

### Newsletter
- One clear lens per issue. Don't stuff unrelated updates together.
- Section titles carry weight — readers skim before they commit.
- The opening paragraph does real work. If it's a greeting, cut it.

## Repurposing cascade

Default flow when turning one anchor into many pieces:

1. **Anchor** — article, video, memo, demo recording, launch doc.
2. **Extract 3–7 atomic ideas** — each a single claim or insight that can stand alone.
3. **Write platform-native variants** per idea, using the playbook above.
4. **Trim redundancy** across outputs — if two posts make the same point in the same shape, kill one.
5. **Align CTAs** to platform intent (X: follow/reply; LinkedIn: comment/DM; TikTok: follow/save; newsletter: reply/forward).

## Deliverable shape

When the user asks for a campaign, return:

- The core angle (one sentence — the through-line across all pieces).
- Platform-specific drafts.
- Suggested posting order (if multi-day).
- CTA variants where appropriate.
- Any missing inputs you need before publishing.

## Pre-publish gate

- [ ] Each draft reads natively for its platform — nothing was cross-pasted.
- [ ] Every hook is specific, not a summary.
- [ ] No hype adjectives survived editing.
- [ ] No two drafts make the same point the same way.
- [ ] CTAs match platform intent and audience trust level.
