# AI-Preferred Content Patterns

## High-Performance Content Structures

### 1. Question-Answer Stacking
Format that directly addresses common questions:

```markdown
## What is [Topic]?

[Direct 2-3 sentence answer]

## Why does [Topic] matter?

[2-3 sentences on importance]

## How do you [do X]?

1. [Step 1]
2. [Step 2]
3. [Step 3]

## Common Use Cases

- [Use case 1]
- [Use case 2]
- [Use case 3]

## FAQ

### Q: [Common question 1]?
A: [Answer]

### Q: [Common question 2]?
A: [Answer]
```

### 2. Definition + Example Pattern
Every concept explained with concrete examples:

```
[Term]: [Clear definition]

Example: [Real-world application]
Why it matters: [Practical significance]
```

### 3. Comparison Tables
AI extracts structured data from tables:

| Feature | [Product A] | [Product B] |
|---------|-------------|-------------|
| Price | $[X] | $[Y] |
| Key Feature | [Desc] | [Desc] |
| Best For | [Use Case] | [Use Case] |

### 4. Step-by-Step Numbered Lists
Numbered steps rank higher than bullet points:

1. Clear first step
2. Specific second step  
3. Detailed third step
4. Expected outcome

### 5. Statistic Sandwich
```
Hook: [Shocking stat]
Context: [What it means]
Implication: [Why it matters]
```

## Content That AI Avoids Citing

### ❌ Avoid These Patterns

1. **Wall of Text** — No breaks, headers, or structure
2. **Old Content** — Information older than 12-18 months
3. **Self-Referential** — "As this blog post says..."
4. **Opinion as Fact** — No backing for claims
5. **Broken Links** — Unverifiable claims
6. **Paywalled Content** — AI can't verify what it can't access
7. **User-Generated** — Forums, Reddit, social posts (low authority)
8. **Promotional** — "Best product ever!" without evidence

## Title/Headline Patterns

### High-Performing Headlines
```
"[Number] Ways to [Achieve X]"
"[Problem]: [Solution] (Full Guide)"
"The Ultimate Guide to [Topic] in [Year]"
"[Tool] vs [Tool]: Which [Wins/Should You Use]"
"How to [Achieve X] in [Y] Steps"
```

### Low-Performing Headlines
```
"Thoughts on [Topic]"
"Our company's perspective on [Topic]"
"Click here to learn about [Topic]"
"[Topic] - The basics"
```

## LLM Optimization Checklist

### Structure
- [ ] Clear H1 matching search intent
- [ ] 2-3 sentence intro answering the query
- [ ] H2s that are questions or phrases
- [ ] Bullet points for lists under 7 items
- [ ] Numbered lists for sequences
- [ ] Comparison tables for multi-option decisions
- [ ] FAQ section for related questions

### Content Quality
- [ ] Factual claims with citations
- [ ] Recent data (within 12 months)
- [ ] Real examples, not generic ones
- [ ] Expert quotes or named sources
- [ ] Data + source cited together

### Technical
- [ ] Schema.org markup (FAQ, HowTo, Article)
- [ ] Proper heading hierarchy (H1 > H2 > H3)
- [ ] Keyphrase in first 100 words
- [ ] Keyphrase in at least one H2
- [ ] Internal links to related content
- [ ] External links to authoritative sources
