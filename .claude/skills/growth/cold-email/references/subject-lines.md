# High-Converting Subject Lines

## By Category

### Curiosity Gap
| Subject Line | Why It Works |
|--------------|--------------|
| "You probably haven't heard of this" | Creates curiosity gap |
| "This is uncomfortable to share" | Reverse psychology |
| "The thing about [Company] we can't say publicly" | Insider intrigue |
| "An experiment we're running" | Novelty, low commitment |
| "I almost didn't send this" | Removes pressure to read |

### Questions
| Subject Line | Why It Works |
|--------------|--------------|
| "Have you tried [X] for [Y]?" | Direct engagement |
| "What's your take on [topic]?" | Invites response |
| "Quick question about [Company]" | Low-friction ask |
| "Ready for [X]?" | Yes-oriented, forward-looking |
| "Is [X] on your roadmap?" | Assumes interest |

### Numbers/Lists
| Subject Line | Why It Works |
|--------------|--------------|
| "[X] things we learned from [Company]" | Specificity, value |
| "[X] ways to improve [metric]" | Clear benefit |
| "[X]% of [role] don't know this" | Loss aversion |
| "The [X] mistakes [role] make" | Authority + education |
| "[X] signs you're wrong about [topic]" | Provocative |

### Social Proof
| Subject Line | Why It Works |
|--------------|--------------|
| "[Mutual connection] suggested I reach out" | Warm intro |
| "[Company] just did [X]" | FOMO |
| "[X] companies like yours use [Y]" | Validation |
| "We help [X] similar companies with [Y]" | Credibility |
| "[Person] said you'd want to see this" | Authority transfer |

### Benefit-First
| Subject Line | Why It Works |
|--------------|--------------|
| "How to get [X] without [pain]" | Removes friction |
| "[X]% lift in [Y] — here's how" | Specific outcome |
| "The shortcut to [X]" | Time-saving |
| "Finally, [X] that works" | Relief from frustration |
| "What top [role] prioritize this quarter" | Authority + timeliness |

### Personalization
| Subject Line | Why It Works |
|--------------|--------------|
| "[First name], quick question" | Human, direct |
| "[Company] + [specific insight]" | Hyper-relevant |
| "Saw your post on [topic]" | Proves research |
| "Congrats on [Company news]" | Relationship-building |
| "Your [metric] compared to [benchmark]" | Data-driven |

## A/B Test Subject Lines

### Test 1: Curiosity vs Direct
```
A: "You probably haven't heard of this"
B: "[Product] helps [Company] with [problem]"
```

### Test 2: Length
```
A: "Quick question"
B: "Quick question about [Company]'s Q4 pipeline"
```

### Test 3: Personalization Depth
```
A: "Hi [First Name]"
B: "[First Name] — saw your post about [topic]"
```

### Test 4: Question vs Statement
```
A: "Do you have 10 minutes for [X]?"
B: "10 minutes on [X] could save you [Y]"
```

### Test 5: Emoji vs No Emoji
```
A: "🚀 [Company] just did [X]"
B: "[Company] just did [X]"
```
*Test emoji carefully — varies by industry*

## Subject Line Formulas

### For SaaS/Tech
```
[Job Title] problems → [X] solutions
We help [company type] with [problem]
[X] signs your [tool/approach] needs upgrade
The [X] mistake[s] [role] make
How [similar company] achieved [metric]
```

### For Sales
```
[X] minutes on [topic]?
Your [metric] benchmark vs [company]
Quick question about [their company]
Congrats on [their news]
[x]% of teams don't know this about [metric]
```

### For Marketing
```
What [top companies] do differently in [year]
[X] content ideas for [platform/format]
Your [channel] isn't working because [X]
The [X] content audit mistakes everyone makes
[X]% open rate? Here's what works now
```

### For Finance/FinTech
```
[X]% of [role] overlook this in [area]
Your [benchmark] vs [company type] average
[X] trends shaping [industry] this quarter
New [regulation/compliance] — what it means for you
How [similar company] reduced [metric] by [X]%
```

### For Healthcare/MedTech
```
[X] things [role] get wrong about [topic]
New research on [condition/treatment]
Your peers are using [X] — here's why
[X] questions every [role] should ask
The [X] guide to [topic] in [year]
```

## Subject Line Formulas by Send Type

### First Cold Email
```
"[First name]" — simple, personal
Quick question about [Company]
[Mutual connection] suggested I reach out
```

### Follow-Up Email
```
Re: [Previous subject]
Following up on [topic]
Did you see my last note?
[X] articles on [topic] you might have missed
Just one thing...
```

### Sequence Email (Position 3-5)
```
[X] things about [topic] you might not know
The [X] we talked about last [time period]
I have a theory about [their situation]
This might be a fit for [Company]
```

### Re-Engagement
```
Checking in from [time ago]
Long time — what's changed at [Company]?
[X] months later — [relevant update]
Still interested in [topic]?
Miss you — and [reason why now is relevant]
```

## Subject Line Length

| Length | Open Rate Impact | Best For |
|--------|------------------|----------|
| < 30 chars | Generally higher | Mobile-heavy audiences |
| 30-50 chars | Optimal range | Most emails |
| > 50 chars | May be truncated | Detailed/personalized |

### Preview Text (Often Overlooked)
```
Subject: Quick question about [Company]
Preview: Have 5 mins to chat about 
         your Q4 pipeline?

Subject: [X] things we learned from [Company]
Preview: Your competitors just did [X] — 
         here's what it means
```

**Rule**: Preview text should complement subject, not repeat it.

---

## Subject Line Checklist

- [ ] Under 50 characters (fits mobile)
- [ ]引 | No ALL CAPS
- [ ] No excessive punctuation!!!
- [ ] Personalization token if possible
- [ ] Clear value or curiosity
- [ ] Preview text complements, doesn't repeat
- [ ] A/B tested variants ready
- [ ] No false promises (spam triggers)
- [ ] Industry-appropriate tone
- [ ] Sender name is recognizable
