# Ad Creative Platform Specifications

## Google Ads

### Asset Sizes

#### Responsive Search Ads
| Asset Type | Sizes | Notes |
|------------|-------|-------|
| Headlines | 3-15, each up to 30 chars | 3 shown at once |
| Descriptions | 2-4, each up to 90 chars | 2 shown at once |
| Final URL | Must match domain | HTTPS preferred |
| Display Paths | 2 optional, up to 15 chars each | Shows in URL |

#### Responsive Display Ads
| Asset Type | Sizes | Notes |
|------------|-------|-------|
| Landscape Logo | 1200x628 or 1200x1200 | At least 1 required |
| Square Logo | 1200x1200 | At least 1 required |
| Headlines | 1-5, up to 50 chars | Auto-generated combinations |
| Descriptions | 1-5, up to 90 chars | Auto-generated combinations |
| Long Headline | Up to 90 chars | Optional |
| Call to Action | Auto (recommended) | Let Google optimize |
| Business Name | Up to 25 chars | Optional |

#### Uploaded Display/Discovery Ads
| Asset Type | Sizes | Notes |
|------------|-------|-------|
| Image | 1.91:1 (1200x628), 1:1 (1200x1200), 
          4:5 (1000x1250), 9:16 (1080x1920) | Multiple sizes required |
| Short headline | Up to 50 chars | Discovery only |
| Description | Up to 90 chars | Discovery only |

#### YouTube Ads
| Asset Type | Sizes | Notes |
|------------|-------|-------|
| Video | Minimum 10 sec | 15 sec or 30 sec recommended |
| Thumbnail | Auto-generated or upload custom | 3 options |
| Headline | Up to 100 chars | Bumper ads only |
| Call to Action | Up to 15 chars | Overlay on video |
| Companion Banner | 300x250 or 300x100 | Optional |

### Character Limits
| Ad Type | Headline | Description | Call to Action |
|---------|----------|-------------|----------------|
| Search | 30 chars | 90 chars | 15 chars |
| Display | 50 chars | 90 chars | Auto |
| Discovery | 50 chars | 90 chars | 15 chars |
| Performance Max | 50 chars | 90 chars | Auto |

## Meta Ads (Facebook/Instagram)

### Image Specs

| Placement | Size | Ratio | Notes |
|-----------|------|-------|-------|
| Feed | 1200x630 | 1.91:1 | Most common |
| Feed | 1080x1080 | 1:1 | Square |
| Stories/Reels | 1080x1920 | 9:16 | Full screen |
| Carousel | 1080x1080 | 1:1 | Per card |
| Right Column | 1200x628 | 1.91:1 | Desktop only |

### Video Specs
| Placement | Min Size | Max Size | Length | Ratio |
|-----------|----------|----------|--------|-------|
| Feed | 600x315 (1.91:1) or 600x600 (1:1) | 4GB | 1 sec - 241 min | 1.91:1 or 1:1 |
| Stories/Reels | 1080x1920 | 4GB | 1-60 sec (Reels), 1-120 sec (Stories) | 9:16 |
| Reels | 1080x1920 | 4GB | Up to 90 sec | 9:16 |

### Text Limits
| Element | Limit |
|---------|-------|
| Primary Text | 63,206 chars (but 125 visible before "see more") |
| Headline | 255 chars |
| Link Description | 63 chars |
| CTA Button | 17 chars (but auto-selected) |

### Character Counts by Placement
| Placement | Primary | Headline | Description |
|-----------|---------|----------|-------------|
| Feed | 125 before "see more" | 40 | 30 |
| Stories | 125 before "see more" | 40 | 30 |
| Right Column | 125 before "see more" | 40 | 30 |
| Marketplace | 125 before "see more" | 40 | 30 |

## LinkedIn Ads

### Sponsored Content

#### Image
| Spec | Details |
|------|---------|
| Max File Size | 5MB |
| Formats | JPG, PNG, GIF |
| Recommended | 1200x627 (1.91:1) |
| Min Width | 1200px |

#### Video
| Spec | Details |
|------|---------|
| Max File Size | 200MB |
| Length | 3 sec - 10 min |
| Min Resolution | 480x360 |
| Formats | MP4 |
| Audio | AAC |

#### Carousel
| Spec | Details |
|------|---------|
| Images | 1-10 cards |
| Image Size | 1080x1080 (1:1) |
| Headline | Max 100 chars per card |
| Description | Max 100 chars per card |

### Sponsored Messaging
| Element | Limit |
|---------|-------|
| Subject Line | 60 chars |
| Message Body | 1,000 chars (but 150 visible) |
| Attachment | 25MB |
| CTA | 25 chars |

### Text Limits
| Element | Limit |
|---------|-------|
| Update Text | 1,300 chars |
| Hashtags | 3 recommended, 30 max |
| Mention | @[company/page name] |
